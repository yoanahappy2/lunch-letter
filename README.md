# 食光提案｜抽一張今天的午餐籤

不知道今天吃什麼？回答三個小問題，從紙袋抽出一張符合預算與偏好的午餐券，讓選餐多一點驚喜。

## 主要功能

- 設定最高預算、主食種類與搭配偏好。
- 點選或向上滑動紙角，抽出午餐券。
- 顯示餐點照片、搭配內容、價格與剩餘預算。
- 同一輪不重複主餐，可回看最近三張餐券。
- 支援新增、修改與刪除餐點，保存常用菜單。

## 使用方式

開啟網站後，依序回答問題，再點選紙袋中的餐券。可以選擇「就吃這一餐」，或「再抽一張」。

餐點價格與照片為示例，可依實際店家調整菜單資料。
